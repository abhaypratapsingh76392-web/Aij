FreeModel Studio (chat + image + video) - Render.com Docker deploy

1) Folder GitHub repo me daalo.  2) Render -> New -> Web Service -> Runtime: Docker.
3) Environment variables:
     FM_API_KEY   = fm_... (FreeModel dashboard se NAYI key; sirf yahin daalo)
     APP_PASSWORD = (optional) set karoge to password manga jayega. Khali = no login.
4) Deploy ke baad URL kholo. Key browser me kabhi nahi jaati, server me hi rehti hai.
Note: bina login ke URL jiske paas hoga wo aapke balance se use kar sakta hai (server par 60 req/min/IP limit hai).
